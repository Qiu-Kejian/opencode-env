## 写作约定（新增服务时遵循）

- 语言：中文；文件命名 `服务-环境.md`（如 `kanboard-wsl.md`），放本目录，并在上表登记。
- 结构至少包含：
  1. **拓扑与版本**：OS/中间件/应用版本、安装路径、属主、端口、访问 URL
  2. **访问与账号策略**：默认账号、首登改密提醒
  3. **部署记录**：关键安装命令、配置文件要点
  4. **运维手册**：启停/重启、备份、升级、回滚、故障排查（日志位置、常见问题）
  5. **安全注意**：暴露的凭据/权限文件位置及撤销命令
  6. **已知限制**
- 任何对实际运行环境的改动（升级、迁移、配置变更）完成后，同步更新该 runbook 的「最近更新」与相关内容。
